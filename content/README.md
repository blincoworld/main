# Content Control

Upload `index.html` and `content-data.json` to the same folder in your GitHub Pages repository.

## How saving works

- Edits autosave to the current browser using localStorage.
- Use **Export full JSON** to create a backup.
- To update the GitHub copy, replace `content-data.json` with the exported file and commit it.
- Direct browser-to-GitHub saving requires the GitHub API or a backend such as a Cloudflare Worker.
